OVERVIEW:
--------
read_parser.py is a comprehensive Python script designed to parse and analyze
AMD almbench dump files (YAML format). It extracts performance and accuracy
data, performs statistical analysis, and generates visual reports with plots.

===============================================================================
KEY FEATURES:
============

1. DATA EXTRACTION:
   - Parses YAML dump files containing test results
   - Extracts multiple data types:
     * IP (Input Values): Hexadecimal input parameters
     * OP (Output Values): Hexadecimal computation results
     * ULP (Error Values): Unit in Last Place error measurements
     * STATUS: Pass/Fail test results
     * DURATION: Execution timing data (nanoseconds)

2. TEST TYPE DETECTION:
   - Automatic classification based on data presence:
     * Accuracy Tests: Focus on ULP error analysis
     * Performance Tests: Include timing measurements
   - Intelligent file naming with _accu or _perf suffixes

3. DATA PROCESSING:
   - Hexadecimal to float conversion using IEEE 754 standard
   - Supports both 32-bit and 64-bit floating-point formats
   - Handles special values (inf, -inf, NaN) appropriately
   - Serial numbering of all extracted values for easy reference

4. STATISTICAL ANALYSIS:
   - Maximum ULP error detection (excludes inf/NaN values)
   - Maximum execution time identification (for performance tests)
   - Pass/Fail ratio calculation
   - Data quality assessment

5. VISUALIZATION:
   - ULP vs Input Value plots with Pass/Fail color coding
   - Timing vs Input Value scatter plots for performance analysis
   - Logarithmic scaling for ULP error visualization
   - High-quality PNG output (300 DPI)

6. CROSS-PLATFORM COMPATIBILITY:
   - Windows and Linux support with automatic path handling
   - Platform-specific usage examples
   - Robust error handling and directory creation

===============================================================================

dump_directory/
