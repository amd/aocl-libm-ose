AOCL LibM - Release Notes - AOCL version 5.2.0
----------------------------------------------

Highlights of AOCL LibM version 5.2.0
-------------------------------------
Build System Enhancements:
 - CMake Build System: Upgraded to a robust, fully integrated CMake build system with comprehensive cross-platform support.
   This enhancement significantly improves the project's modularity, scalability, and maintainability.
 - Dynamic and Static Linking of aocl-utils: Updated the library to support both dynamic and static linking (Default) options

API Additions and Optimizations:
 - New API – erfc: Added erfc API with scalar and vector variants for both float and double precision on Zen platforms.
 - Function Optimizations and Vector Support: Optimized the performance of functions for Zen and AVX2 architectures and
   added vector and vector array variants for: erfcf, erf, asin, acos, cosh, tan, atan and tanh.
 - Enhanced performance testing framework with comprehensive validation for all optimized APIs.

Other Improvements:
 - Coverity Fixes: Addressed and resolved Coverity-reported issues to improve code quality and reliability.
