Summary

These flowcharts illustrate the complete execution flow of the AMD LibM test suite, from command-line parsing through test execution and result serialization. Key aspects covered:

  • Main execution paths - Initialization, library loading, and cleanup
  • YAML processing - Configuration parsing and test generation
  • Variant dispatch - Routing to appropriate type-specific handlers
  • Test execution modes - Unit tests, range tests, and VRA tests
  • ULP verification - Accuracy computation and threshold checking
  • Performance measurement - Timing and throughput calculation
  • Data flow - Structure relationships and transformations
  • Error handling - Recovery strategies for various failure modes

The modular design allows for independent testing of each component while maintaining a clear overall execution sequence.
